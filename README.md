# Segurança do Trabalho – CBPMESP

Material de estudo interativo baseado no resumo de Segurança do Trabalho – CBPMESP (Aulas 1 a 20).

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `seguranca-cbpmsp`.
2. Envie o arquivo `index.html` deste pacote para o repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Clique em **Save**.
7. Aguarde a publicação. O GitHub fornecerá o endereço público do site.

O projeto é um site estático: não precisa de banco de dados, Node.js ou servidor próprio.
